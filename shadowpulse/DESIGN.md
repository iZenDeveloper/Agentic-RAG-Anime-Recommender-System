# ShadowPulse design system

## World

**Field instrument report** — a cool daylight paper ledger for visibility probes. Not neon SaaS, not cream-serif startup, not purple glow.

## Tokens

| Token | Value | Role |
|---|---|---|
| Paper | `#E4EAEF` | Page ground (cool stone, not cream) |
| Ink | `#141C22` | Primary text / primary button |
| Mute | `#5A6974` | Secondary copy |
| Signal | `#0D5C4A` | Affirmative / Clear / links |
| Warn | `#7A5200` | Inconclusive / disclaimer |
| Danger | `#8C2E2E` | Restricted |
| Line | `#C2CCD4` | Hairline rules |

## Type

- Display / brand: **Fraunces** (roman only — no italic-serif hero slop)
- Body: **Source Sans 3**
- Data / badges / timestamps: **IBM Plex Mono**

## Layout rules

- Brand wordmark is the hero. One headline. One support line. One scan cluster.
- No kickers/eyebrows. No pulse rings. No radial cyan halos. No nested cards.
- Results are hairline rows, not card grids.
- Score is a large tabular number, not a glowing conic ring.
- Motion: brand enter, ink-sweep while scanning, score reveal — nothing else decorative.

## Anti-slop (Impeccable)

Rejected on purpose: Inter, cyan-on-dark, purple gradients, cream+terracotta, glass blur decoration, icon tiles, gradient text, bounce easing, status-dot pulse, hero chips.
