# ShadowPulse

Public visibility / shadowban signal scanner for creators and social admins.

## Product truth

- **Audience:** creators, social admins, agencies checking public reach limits without logging into the target account.
- **Job to be done:** enter a public handle → get an honest per-signal report (Clear / Restricted / Inconclusive) with confidence and method.
- **Non-goals:** password OAuth, “unban” services, fake certainty, private data scraping.
- **Tone:** direct, technical, English UI. Prefer “unclear” over false Restricted.
- **Evidence rule:** only externally observable public signals; official in-app checks are always linked.

## Surfaces

- Landing one-shot scan (primary)
- Platform SEO landings `/x` … `/threads`
- Methodology + manual check guides
- 24h share links
